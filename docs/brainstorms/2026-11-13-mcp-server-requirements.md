# Cistory MCP 서버 요구사항

## Summary

Cistory에 원격 MCP 서버를 붙여, 소유자가 직접 운영하는 에이전트가 정적 토큰으로 위치·지출·건강·작업·포트폴리오 기록을 조회하고 일부 정정을 수행하게 한다. 도구는 도메인별 조회가 기본이고, Cistory만 계산할 수 있는 두 가지(납입금 리밸런싱 배분, 과거 이동 기록 기반 소요시간 통계)를 더한다. 토큰마다 스코프와 IP/국가 잠금을 걸고, 모든 호출을 감사 로그에 남긴다.

---

## Problem Frame

Cistory에는 이미 개인 비서가 필요로 하는 맥락이 모여 있다. 지금 어디에 있는지, 평소 그 구간을 무슨 수단으로 몇 분에 가는지, 이번 달 어디에 돈을 썼는지, 어젯밤 몇 시간 잤는지, 지난주 무엇을 커밋했는지, ISA 계좌의 목표 비중과 현재 보유 내역까지 있다. 그런데 이 데이터는 웹 대시보드에서 사람이 눈으로 볼 때만 쓸 수 있다.

소유자가 에이전트에게 "7시까지 강남 가야 하는데", "이번 달 식비 왜 늘었어", "ISA에 100만원 넣을 건데 어디에 얼마씩 넣어야 비율이 맞아"라고 물어도 에이전트는 답할 재료가 없다. 소유자가 대시보드를 열어 숫자를 옮겨 주거나 직접 계산해야 한다.

Cistory는 지금까지 민감 데이터가 밖으로 나가는 경로를 일부러 막아 왔다. Sentry 스크럽, overview의 ECG 차단 allowlist, 검색어 텔레메트리 제거가 그 예다. 외부 에이전트에 문을 여는 순간 그 경계가 가장 넓은 출구가 된다. 에이전트는 Anthropic 외 모델 제공자나 자체 로그로 데이터를 넘길 수 있다.

---

## Actors

- A1. 소유자: 토큰을 발급·폐기하고 잠금을 설정하며 감사 로그를 확인한다. Cistory의 유일한 사용자다.
- A2. 자체 에이전트: 소유자가 운영하는 개인 비서 에이전트(Hermes, Agent SDK 기반 봇 등). 발급받은 토큰으로 MCP에 접속한다.
- A3. Cistory MCP 서버: 토큰·스코프·잠금을 검증하고 도구를 실행하며 감사 기록을 남긴다.

---

## Key Decisions

**정적 토큰, OAuth 없음.** 대상 클라이언트가 소유자의 자체 에이전트뿐이라 정적 bearer 토큰으로 충분하다. claude.ai 커스텀 커넥터처럼 OAuth 동적 클라이언트 등록이 필요한 클라이언트는 이번 범위에서 지원하지 않는다. 토큰 발급·폐기는 기존 API 키(OwnTracks, Toss, Health import)와 같은 방식으로 다룬다.

**도메인별 조회 도구가 기본, 계산 도구는 두 개만.** 조합과 추론은 에이전트가 맡는다. Cistory는 에이전트가 외부에서 얻을 수 없는 계산만 직접 한다. 하나는 목표 비중과 보유 내역이 필요한 리밸런싱 배분이고, 다른 하나는 장소 근접 매칭과 KST 처리가 필요한 개인 이동 소요시간 통계다. 질문 유형마다 고수준 도구를 만드는 방식은 유지 비용이 계속 늘어서 택하지 않았다. 범용 쿼리 도구는 스코프와 민감 필드 통제를 에이전트에게 넘기게 되어서 택하지 않았다.

**실시간 길찾기는 하지 않는다.** 소요시간 도구는 "내가 이 구간을 실제로 얼마에 갔는지"만 돌려준다. 가 본 적 없는 경로나 실시간 교통은 에이전트의 지도 도구가 맡는다.

**스코프는 세 개: read, sensitive-read, write.** 토큰마다 조합해서 부여한다. 민감 데이터는 좁게 정했다. ECG·불규칙 심박, 송금 상대 개인 이름, 계좌명, 원문 알림 텍스트, 증권 계좌번호만 sensitive-read 뒤에 둔다. 가맹점명, 원시 GPS, 사진 메타데이터·썸네일은 일반 read에 둔다. 소유자가 가맹점 노출은 크게 상관없다고 판단했다.

**넓은 read의 위험은 잠금과 감사로 상쇄한다.** 일반 read에 전체 이동 기록이 포함되므로, 토큰이 유출돼도 등록된 IP 대역·국가 밖에서는 쓸 수 없게 한다. 쓰인 흔적도 모두 남긴다.

## Requirements

**연결과 인증**
- R1. 원격 MCP 클라이언트가 HTTPS로 Cistory MCP 서버에 접속할 수 있다.
- R2. 모든 MCP 요청은 소유자가 발급한 bearer 토큰이 있어야 하며, 토큰이 없거나 폐기·만료된 요청은 도구 실행 전에 거부한다.
- R3. 소유자는 설정 화면에서 토큰을 여러 개 발급하고, 각각에 이름·스코프·잠금을 지정하며, 개별 폐기할 수 있다.
- R4. 토큰 원문은 발급 시 한 번만 보여 주고, 이후에는 식별용 접두부와 마지막 사용 시각만 표시한다.

**스코프**
- R5. 토큰은 read, sensitive-read, write를 임의로 조합해 가진다. 도구 목록에는 토큰이 실행할 수 있는 도구만 나타난다.
- R6. sensitive-read가 없는 토큰의 응답에서는 민감 필드를 빼거나 가린다. 민감 필드는 ECG·불규칙 심박, 송금 상대 개인 이름, 계좌명, 원문 알림 텍스트, 증권 계좌번호다.
- R7. 스코프 밖 도구 호출은 거부하고 감사 로그에 남긴다.

**IP·국가 잠금**
- R8. 토큰마다 허용 IP 대역(CIDR 목록)과 허용 국가 목록을 선택적으로 설정할 수 있다. 둘 다 설정하면 두 조건을 모두 만족해야 한다.
- R9. 잠금 조건을 만족하지 않는 요청은 토큰이 유효해도 거부한다. 국가를 판별할 수 없는 요청은 국가 잠금이 걸린 토큰에서 거부한다.
- R10. 잠금 위반은 감사 로그에 남기고 소유자에게 알린다.

**조회 도구 (read)**
- R11. 현재 위치: 가장 최근 위치 좌표, 그 시각과 정확도, 지금 머무는 장소(저장 장소 이름 포함)를 돌려준다. 마지막 위치가 오래됐다면 에이전트가 판단할 수 있도록 경과 시간을 함께 준다.
- R12. 위치 기록: 기간별 방문(장소·시각·체류 시간), 이동(수단·소요시간·거리), 지하철 이용, 원시 GPS 포인트를 조회한다.
- R13. 저장 장소와 여행: 저장 장소 목록, 여행 목록과 상세를 조회한다.
- R14. 지출: 기간·카테고리별 합계, 건별 거래(금액·시각·카테고리·가맹점), 월말 예측을 조회한다.
- R15. 건강: 수면, 걸음 수, 심박, 운동, 체중·체성분의 기간별 요약과 일별 값을 조회한다. ECG·불규칙 심박은 sensitive-read에서만 조회한다.
- R16. 작업: 커밋과 AI 요약, WakaTime 코딩 시간을 기간별로 조회한다.
- R17. 포트폴리오: 계좌별 보유 종목·평가액, 목표 비중, 수익률(TWR)을 조회한다.
- R18. 회고: 주·월·년 overview 스냅샷과 AI 내러티브를 조회하고, 기존 검색과 같은 범위로 교차 검색한다.
- R19. 사진: 기간·위치별 사진 메타데이터와 썸네일을 조회한다. NSFW 검사를 통과한 사진만 노출하는 기존 규칙을 그대로 따른다.
- R20. 모든 시각은 KST 기준으로 해석되고 반환되며, 날짜 입력은 KST 날짜로 받는다.

**계산 도구 (read)**
- R21. 납입금 리밸런싱: 계좌와 납입 금액을 받아, 목표 비중에 가장 가까워지도록 종목별 매수 금액과 수량을 제안한다. 매도 없이 신규 납입만으로 맞춘다. 결과에는 계산 기준 시점의 보유·가격을 함께 준다.
- R22. 개인 소요시간: 출발지와 도착지(좌표 또는 저장 장소)를 받아, 과거 실제 이동 중 그 구간에 해당하는 기록을 찾고 수단별 횟수·중앙값·느린 경우(상위 80%) 소요시간·주 이용 노선을 돌려준다. 시간대를 지정하면 그 시간대 이동만 집계한다.
- R23. 소요시간 도구는 해당 구간 기록이 없으면 추정치를 지어내지 않고 "기록 없음"을 돌려준다.

**쓰기 도구 (write)**
- R24. 저장 장소를 추가·이름 변경·삭제한다.
- R25. 거래의 지출 카테고리와 지출/수입/무시 분류를 정정한다.
- R26. 여행 이름을 바꾸고, 여행을 "여행 아님"으로 표시하고, 수동 여행을 추가한다. "여행 아님"은 웹 UI와 같은 정정 경로(제외 장소 생성)를 따른다.
- R27. 쓰기 결과가 overview 등 파생 데이터에 영향을 주면 웹 UI에서 같은 정정을 했을 때와 똑같이 재계산이 걸린다.

**감사 로그**
- R28. 성공·실패·거부를 가리지 않고 모든 MCP 호출을 기록한다. 기록 항목은 시각, 토큰, 도구, 인자 요약, 반환 건수, 접속 IP, 판별된 국가, 결과, 거부 사유다.
- R29. 반환된 데이터 본문은 감사 로그에 저장하지 않는다. 인자 요약에도 민감 필드 값은 남기지 않는다.
- R30. 쓰기 호출은 바꾸기 전과 후의 값을 함께 기록한다.
- R31. 소유자는 설정 화면에서 감사 로그를 토큰·도구·결과·기간별로 조회할 수 있다.
- R32. 잠금 위반, 폐기된 토큰 사용 시도, 스코프 위반은 소유자에게 알린다. 같은 원인이 반복되면 알림을 묶어서 보낸다.
- R33. 감사 로그는 소유자가 직접 지우기 전까지 보존한다. 감사 로그 자체는 MCP 도구로 노출하지 않는다.

**운영**
- R34. MCP 요청 처리가 웹 컨테이너의 다른 요청을 멈추지 않도록 무거운 계산을 제한한다. 토큰별 호출 빈도 제한도 둔다.
- R35. MCP 요청 경로의 Sentry 이벤트와 로그에는 도구 인자와 응답 본문이 들어가지 않는다.

## Key Flows

- F1. 출발 시각 계획
  - **Trigger:** 소유자가 에이전트에게 "7시까지 강남역 가야 해"라고 말한다.
  - **Actors:** A1, A2, A3
  - **Steps:** 에이전트가 현재 위치를 조회하고, 현재 위치→강남역 개인 소요시간을 조회한다. 기록이 있으면 중앙값과 느린 경우 기준으로 출발 시각을 제안하고, 기록이 없으면 자기 지도 도구로 넘어간다.
  - **Outcome:** "지하철로 평소 38분, 늦으면 47분 — 6시 10분쯤 나가면 된다." 호출 두 건이 감사 로그에 남는다.
  - **Covered by:** R11, R22, R23, R28

- F2. ISA 납입 배분
  - **Trigger:** "이번 ISA에 100만원 넣을 건데 어디에 얼마씩?"
  - **Actors:** A1, A2, A3
  - **Steps:** 에이전트가 계좌 목록을 조회해 ISA 계좌를 찾고, 리밸런싱 도구에 100만원을 넘긴다.
  - **Outcome:** 종목별 매수 금액·수량과 납입 후 예상 비중을 받는다. sensitive-read가 없으면 계좌번호는 가려진다.
  - **Covered by:** R6, R17, R21

- F3. 유출된 토큰
  - **Trigger:** 한국·자택 IP 대역으로 잠긴 read 토큰이 해외 IP에서 사용된다.
  - **Actors:** A3, A1
  - **Steps:** 서버가 토큰을 확인하지만 잠금 조건을 만족하지 않아 거부하고, 거부 기록을 남기며, 소유자에게 알린다.
  - **Outcome:** 데이터는 하나도 반환되지 않는다. 소유자는 감사 로그에서 시도를 확인하고 토큰을 폐기한다.
  - **Covered by:** R9, R10, R28, R32

## Acceptance Examples

- AE1. **Covers R6.** sensitive-read가 없는 토큰으로 지출 거래를 조회하면 가맹점명은 보이지만, 개인 송금 상대 이름과 계좌명은 가려지고 원문 알림 텍스트는 빠진다.
- AE2. **Covers R5, R7.** read만 있는 토큰의 도구 목록에는 쓰기 도구가 없다. 그래도 쓰기 도구 이름으로 직접 호출하면 거부되고 감사 로그에 스코프 위반으로 남는다.
- AE3. **Covers R8, R9.** IP 대역만 설정된 토큰은 국가를 판별할 수 없어도 대역 안이면 허용된다. 국가 잠금이 있는 토큰은 국가를 판별할 수 없으면 거부된다.
- AE4. **Covers R22, R23.** 집→회사 이동 기록이 지하철 40건·도보 0건이면 지하철 통계만 나오고, 도보는 "기록 없음"으로 표시된다.
- AE5. **Covers R26, R30.** 에이전트가 여행을 "여행 아님"으로 표시하면 웹 UI와 같은 제외 장소가 생기고, 감사 로그에 원래 여행 정보와 생성된 제외 장소가 함께 남는다.

---

## Scope Boundaries

- 동기화·overview 재계산·데이터 복구 트리거는 MCP로 노출하지 않는다.
- OAuth, claude.ai·모바일 Claude 커스텀 커넥터, Claude Code 전용 운영 도구는 다음으로 미룬다.
- 범용 쿼리(SQL) 도구는 만들지 않는다.
- 실시간 길찾기·대중교통 경로 탐색은 하지 않는다.
- 원본 사진 다운로드, 증권 주문, 결제처럼 외부 시스템에 영향을 주는 동작은 하지 않는다.
- 다중 사용자 지원은 고려하지 않는다. Cistory는 소유자 전용이다.

## Dependencies / Assumptions

- 국가 잠금은 접속 IP를 국가로 판별할 수 있다는 전제에 기대고 있다. 서버 앞단 프록시(예: Cloudflare)가 국가 정보를 붙여 주는지는 확인되지 않았다.
- 개인 소요시간 통계는 기존 이동·구간·지하철 매칭 데이터의 품질에 기댄다. 위치 파이프라인은 하루 단위로 처리되므로 오늘 이동은 집계에 늦게 들어간다.
- 현재 위치의 신선도는 OwnTracks 전송 주기에 달려 있다.
- 리밸런싱은 마지막 KIS 스냅샷 가격 기준이며, 장중 실시간 가격이 아니다.
