# Korean Administrative Boundary GeoJSON

Download 시군구 boundary GeoJSON from:
- 통계청: https://sgis.kostat.go.kr/
- Or use simplified version from: https://github.com/southkorea/seoul-maps

Place the file as `korea-sigungu.json` in this directory.
Each feature should have properties: SIG_CD (code), SIG_KOR_NM (Korean name)
